# Volume I — published OCR edition

Human-readable pipeline output for Maxwell, *A Treatise on Electricity
and Magnetism*, Volume I (1873).

Maxwell's text is public domain. This directory claims no copyright in
the OCR, chapter JSON, or other mechanical extracts. See
[LICENSE](../LICENSE).

| Path | What it is |
|------|------------|
| `volume_1_ocr.md` | Full-volume OCR in Markdown (LaTeX equations preserved) |
| `VOLUME_1_PROCESSING_REPORT.md` | Processing metrics and quality notes |
| `PROCESSING_SUMMARY.txt`, `MASTER_SUMMARY.txt` | Short run summaries |
| `VOLUME_1_PART_1_CHAPTERS/` | Part I (Electrostatics) chapter JSON |
| `VOLUME_1_PART_2_CHAPTERS/` | Part II (Electrokinematics) chapter JSON |
| `VOLUME_1_PART_1_ELECTROSTATICS.JSON` | Combined Part I |
| `VOLUME_1_PART_2_ELECTROKINEMATICS.JSON` | Combined Part II |
| `VOLUME_1_PRELIM_TOC.JSON` | Preliminary TOC |
| `VOLUME_1_PLATES_DIAGRAMS.JSON` | Plates / diagrams index |
| `VOLUME_1_ALL_PAGES_PRELIMINARY_TO_CHAPTER XII.JSON` | Early-pages extract |

Figures in `volume_1_ocr.md` may point at Mathpix CDN URLs from the
original OCR run. The source scan is
`input/15773-A Treatise On Electricity And Magnetism Vol-i.pdf`.

Raw Mathpix dumps (`RAW_OUTPUTS/`), processing logs, and the large
direct API JSON are kept local and are not published.
