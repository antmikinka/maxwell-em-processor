## Functions of Several Variables

A function of two variables is a rule which assigns for each ( $x, y$ ) in a domain $D \subset \mathbf{R}^{2}$ a real number $z=f(x, y)$.

A function of two variables can be given by a formula, a graph or a table.
Formula: $f(x, y)=x^{2}+y^{2}$
Graph: $\{(x, y, z) \mid(x, y) \in D$ and $z=f(x, y)\}$
![](https://cdn.mathpix.com/cropped/2025_11_27_f6f00ee83ae0389c66b5g-02.jpg?height=723&width=833&top_left_y=879&top_left_x=312)

Graph of $z=x^{2}+y^{2}$ in the domain

$$
D=\left\{(x, y) \mid x^{2}+y^{2} \leq 4\right\}
$$
![](https://cdn.mathpix.com/cropped/2025_11_27_f6f00ee83ae0389c66b5g-02.jpg?height=800&width=689&top_left_y=832&top_left_x=1504)

Since $f(1,1)=2$, the point $\mathrm{P}(1,1,2)$ is on the graph of $f$.

## Functions of Several Variables

Unless otherwise specified, the Domain of the function $f(x, y)$ is the set of all points $(x, y)$ for which $f(x, y)$ is a well defined real number.

The Range of the function $f(x, y)$ is the set $\{z \mid z=f(x, y)$ with $(x, y) \in$ Domain $\}$
Example: Find the domain: $f(x, y)=\frac{\sqrt{x-y+3}}{x+2}$
The function is defined when $x-y+3 \geq 0$ and $x+2 \neq 0$

## Domain:

$4-x^{2}-y^{2} \geq 0 \Rightarrow x^{2}+y^{2} \leq 4$
![](https://cdn.mathpix.com/cropped/2025_11_27_f6f00ee83ae0389c66b5g-10.jpg?height=656&width=756&top_left_y=738&top_left_x=235)

The surface is the top half of the sphere of radius 2 :

$$
x^{2}+y^{2}+z^{2}=4
$$

## Range:

The largest value of $z$ is $\sqrt{4}=2$, obtained when $x=0$ and $y=0$.
On the other hand, the square root is always non negative, thus $z \geq 0$ and the range is the interval $[0,2]$

## Function of Several Variables

A function of $n$ variables assigns a number $z=f\left(x_{1}, x_{2}, \ldots, x_{n}\right)$ to an $n$-tuple $\left(x_{1}, x_{2}, \ldots, x_{n}\right)$

Example: Consider the function of three variable $f(x, y, z)=x^{2} \ln (x-y+z)$
a) Evaluate $f(3,6,4)$

$$
f(3,6,4)=3^{2} \ln (3-6+4)=9 \ln (1)=0
$$
b) Find the domain of $f$
$$
\mathrm{D}=\{(x, y, z) \mid x-y+z>0\}
$$

The plane $x-y+z=0$ divides the space in two parts. The part of space above the plane constitutes the domain of the function.
c) Find the range of $f$
![](https://cdn.mathpix.com/cropped/2025_11_27_f6f00ee83ae0389c66b5g-11.jpg?height=810&width=975&top_left_y=785&top_left_x=1426)

Since the natural logarithmic function takes on all possible real values, the domain of the function is $(-\infty, \infty)$

## Function of Several Variables

Example: The temperature in a region where there is a heat source at the origin is given by

$$
T=\frac{1000}{x^{2}+y^{2}+z^{2}} \text { for } x^{2}+y^{2}+z^{2} \geq 1
$$

We cannot graph this "surface" because we would need four dimensions, but if we set $T(x, y, z)=k$ with $k$ constant, we obtain level surfaces which in this context are isotherms.
![](https://cdn.mathpix.com/cropped/2025_11_27_f6f00ee83ae0389c66b5g-12.jpg?height=726&width=911&top_left_y=923&top_left_x=127)
$T=250$ on the surface
$x^{2}+y^{2}+z^{2}=4$

$$
\frac{1000}{x^{2}+y^{2}+z^{2}}=k
$$

We can pick arbitrary values for $k$.
Let's pick $k=1000$ and $k=250$

$$
\begin{aligned}
& k=1000 \Rightarrow \frac{1000}{x^{2}+y^{2}+z^{2}}=1000 \Rightarrow x^{2}+y^{2}+z^{2}=1 \\
& k=250 \Rightarrow \frac{1000}{x^{2}+y^{2}+z^{2}}=250 \Rightarrow x^{2}+y^{2}+z^{2}=4
\end{aligned}
$$
