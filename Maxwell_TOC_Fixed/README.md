# Maxwell_TOC_Fixed — intermediate TOC split

This tree is an **intermediate, unsuccessful** attempt to split Volume I
into Parts / Chapters / Articles. Folder names are OCR snippets, not
Maxwell's real hierarchy. It is published so the pipeline work is
inspectable, not as the edition to read.

Read these instead:

- `MAXWELL_VOLUME_1_MASTER_OUTPUT/` — Volume I edition
- `MAXWELL_VOLUME_2_MASTER_OUTPUT/` — Volume II edition
- `input/` — 1873 scans

The JSON here reproduces Maxwell's 1873 text. That text is public
domain. **No copyright is claimed.** See [LICENSE](../LICENSE).

`Maxwell_TOC/` (without `_Fixed`) is an earlier local attempt and is
not published.
