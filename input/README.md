# Source documents

This directory holds the scans used by the pipeline.

## In this repository

These files are James Clerk Maxwell, *A Treatise on Electricity and
Magnetism* (1873). That work is in the public domain. No copyright is
claimed in the scans.

| File | Volume |
|------|--------|
| `15773-A Treatise On Electricity And Magnetism Vol-i.pdf` | Volume I |
| `15774-A Treatise On Electricity And Magnetism Vol-ii.pdf` | Volume II |

The volume README files transcribe Maxwell's tables of contents. They
are also public domain. See [LICENSE](../LICENSE).

## Not in this repository

Any other local PDF under `input/` is **not** part of this project and
is not licensed by it. In particular, a modern textbook chapter that
may exist on a developer's machine must not be committed or published.

Organized OCR of the Treatise lives in
`MAXWELL_VOLUME_1_MASTER_OUTPUT/` and
`MAXWELL_VOLUME_2_MASTER_OUTPUT/` (including `RAW_OUTPUTS/`).
`Maxwell_TOC_Fixed/` is an intermediate TOC split, not the edition.
